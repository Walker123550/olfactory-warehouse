# 新手提示面板说明

录入界面现在增加了“新手提示”面板，用来解决刚开始闻香时词汇不足、分类不确定的问题。

## 使用方式

1. 在 `一级分类` 里选择一个香气家族，例如 `柑橘`、`花香`、`木质`。
2. 系统会自动刷新下面的候选项：
   - 二级分类
   - 气味关键词
   - 对比样本
   - 归属锚点
   - 时间变化提示
3. 点击候选词会填入或追加到对应字段。
4. 点击 `填入推荐` 会把当前分类下最常见的一组词先放进表单。

## 设计原则

提示词按经典香气家族组织：

- 柑橘
- 花香
- 木质
- 草本
- 辛香
- 树脂
- 果香
- 动物

每个家族都给出适合新手比较的词，而不是抽象评价。比如推荐 `酸`、`果皮苦`、`青绿`，而不是 `高级`、`好闻`。

## 注意

这些候选词只是训练脚手架，不是标准答案。实际填写时仍以自己闻到的气味为准。如果候选词不准确，可以直接手动修改或补充。
